# 🚀 Link-in-Bio Webpage (Mini Portfolio Hub)

A modern and stylish **link-in-bio webpage** built to solve the limitation of adding multiple links on platforms like Instagram.

Instead of sharing multiple links separately, this project allows you to showcase **all your important links in one place** using a single URL.

---

## 🌟 Purpose

* Provide a **single access point** for all important links
* Improve **personal branding and online presence**
* Make sharing profiles and projects **simple and efficient**

---

## ✨ Features

* 🔮 Glassmorphism UI design
* 📱 Fully responsive (mobile-friendly)
* 🎯 Grid-based icon layout (modern app-style UI)
* ⚡ Smooth animations and hover effects
* 🔗 Easy to update links

---

## 💡 Why I Built This

Social media platforms like Instagram allow only limited links in bio.
This project solves that problem by creating a **centralized link hub**, making it easier to share everything through one link.
